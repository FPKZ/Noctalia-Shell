# Telegram

Generate a Material You color theme for Telegram Desktop using the Noctalia palette.

Enable **Telegram** in **Noctalia Settings → Templates**. The generated file is `$XDG_CONFIG_HOME/telegram-desktop/themes/noctalia.tdesktop-theme` (normally `~/.config/telegram-desktop/themes/noctalia.tdesktop-theme`). Import and apply that file through Telegram Desktop's custom-theme controls.

This template only generates the theme file: it does not select it, modify Telegram's settings, or issue a reload command. Re-import the updated file when you want to apply a regenerated palette. Keep custom edits outside the generated file, which is overwritten on regeneration.
